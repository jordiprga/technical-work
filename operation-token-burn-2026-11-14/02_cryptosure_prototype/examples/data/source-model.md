# Modelo sintético para demostrar el flujo

La secuencia es pública, determinista y alternante. Su min-entropía como variable
conocida es cero. Aprueba estos health tests porque no contiene rachas largas ni
ventanas dominadas por un símbolo. Esto demuestra por qué un PASS de RCT/APT no
es evidencia suficiente de impredecibilidad ni estimación de entropía.

No se representa ningún producto o arquitectura de Quside. Los parámetros no son
criterios de aceptación para un laboratorio.
